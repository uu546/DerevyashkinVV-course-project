## Цель этапа

**В рамках этапа решаются следующие задачи:**

1. **Создание структуры проекта** — организация пакетов и классов в соответствии со слоями PCMEF.

2. **Реализация слоя Entity** — создание JPA-сущностей с бизнес-методами, отражающими предметную область.

3. **Реализация слоя Foundation** — создание репозиториев (интерфейсов и реализаций) для доступа к данным.

4. **Обеспечение соответствия архитектуре** — проверка направленности зависимостей и принципов SOLID.

**Результат этапа:** Рабочее ядро системы, готовое к тестированию и интеграции с клиентской частью.

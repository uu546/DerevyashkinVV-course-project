## Введение

### О системе

**«Система управления складом» (Warehouse Management System)** — это веб-приложение для автоматизации складского учёта, которое позволяет:

- Отслеживать остатки товаров на складах и в ячейках
- Оформлять приёмку товаров
- Оформлять отгрузку товаров
- Перемещать товары между ячейками
- Просматривать сводную информацию по складам

### Целевая аудитория

| Роль | Описание |
|------|----------|
| **Менеджер склада** | Полный доступ ко всем операциям |
| **Кладовщик** | Выполнение операций приёмки, отгрузки, перемещения (если назначена роль MANAGER) |
| **Руководитель** | Просмотр сводки |

## Сводка по складу

### Описание страницы

Страница сводки по складу отображает актуальную информацию о всех остатках товаров в системе.

![a](/docs/08-ui/images/summary.png)

### Структура страницы

#### 1. Общая статистика

В верхней части страницы отображаются четыре ключевых показателя:

| Показатель | Описание |
|------------|------------|
| Склады | Общее количество складов в системе |
| Ячейки | Общее количество ячеек хранения |
| Позиции | Количество уникальных товаров на складе |
| Всего единиц | Общее количество единиц товаров на всех складах |

#### 2. Детальная информация по складам

Каждый склад представлен в виде отдельной карточки:

| Элемент | Описание |
|----------|----------|
| Название склада | Наименование склада |
| Адрес | Физический адрес склада |
| Всего: X шт. | Общее количество товаров на складе |

#### 3. Информация по ячейкам

Внутри каждого склада отображаются ячейки хранения:

| Элемент | Описание |
|----------|----------|
| Название ячейки | Идентификатор ячейки (например, «А-1») |
| Тип ячейки | Тип хранения (Стеллаж, Паллета, Холодильник и т.д.) |
| X шт. | Количество товаров в ячейке |

#### 4. Таблица товаров

Для каждой ячейки отображается таблица товаров:

| Колонка | Описание |
|----------|----------|
| ID | Уникальный идентификатор товара |
| Товар | Наименование товара |
| Ед. изм. | Единица измерения (шт, кг, л) |
| Кол-во | Количество товара в ячейке |
| Скоропорт | Признак скоропортящегося товара (Да/Нет) |

### Обновление данных

Для обновления информации нажмите кнопку «Обновить» в правом верхнем углу страницы.

## Приёмка товаров

### Доступность

Страница доступна только для пользователей с ролью MANAGER.

### Описание страницы

Страница приёмки товаров позволяет оформить поступление одного или нескольких товаров на склад за один запрос.

![a](/docs/08-ui/images/receipt.png)

### Пошаговая инструкция

#### Шаг 1: Выбор целевой ячейки

- В поле «Локация (ячейка) для приёмки» выберите ячейку, куда будут размещены товары
- В выпадающем списке отображаются все доступные ячейки с их названиями и ID

#### Шаг 2: Добавление товаров

Для каждого товара:

- В поле «Товар» выберите товар из выпадающего списка
- Список содержит наименование товара, единицу измерения и ID
- В поле «Количество» укажите количество товара (целое число больше 0)

#### Шаг 3: Добавление нескольких товаров

- Нажмите кнопку «+ Добавить товар» для добавления новой позиции
- При необходимости удалите позицию кнопкой «Удалить»

#### Шаг 4: Подтверждение операции

- Проверьте правильность введённых данных
- Нажмите кнопку «Оформить приёмку»

### Результат

- При успешном выполнении операции вы будете перенаправлены на страницу сводки
- Остатки товаров в выбранной ячейке будут увеличены

### Пример

**Входные данные:**

- Ячейка: Стеллаж А-1 (ID: 1)
- Товар 1: Кирпич красный — 100 шт
- Товар 2: Цемент М500 — 50 шт

**Результат:**

- Остатки кирпича в ячейке А-1: +100
- Остатки цемента в ячейке А-1: +50

## Отгрузка товаров

### Доступность

Страница доступна только для пользователей с ролью MANAGER.

### Описание страницы

Страница отгрузки товаров позволяет оформить списание одного или нескольких товаров со склада за один запрос.

![a](/docs/08-ui/images/shipment.png)

### Пошаговая инструкция

#### Шаг 1: Выбор исходной ячейки

- В поле «Ячейка для отгрузки (общая для всех товаров)» выберите ячейку, из которой будут отгружены товары
- В выпадающем списке отображаются ячейки, в которых есть все выбранные товары

#### Шаг 2: Добавление товаров

Для каждого товара:

- В поле «Товар» выберите товар из выпадающего списка
- Отобразится таблица «Доступные остатки для выбранного товара» — здесь показано, в каких ячейках и в каком количестве есть этот товар
- В поле «Количество» укажите количество товара для отгрузки (не более доступного)

#### Шаг 3: Добавление нескольких товаров

- Нажмите кнопку «+ Добавить товар» для добавления новой позиции
- При необходимости удалите позицию кнопкой «Удалить»

#### Шаг 4: Подтверждение операции

- Проверьте правильность введённых данных
- Нажмите кнопку «Оформить отгрузку»

### Результат

- При успешном выполнении операции вы будете перенаправлены на страницу сводки
- Остатки товаров в выбранной ячейке будут уменьшены

### Пример

**Входные данные:**

- Ячейка: Стеллаж А-1 (ID: 1)
- Товар 1: Кирпич красный — 10 шт (доступно 100)
- Товар 2: Цемент М500 — 5 шт (доступно 50)

**Результат:**

- Остатки кирпича в ячейке А-1: -10
- Остатки цемента в ячейке А-1: -5

## Перемещение товаров

### Доступность

Страница доступна только для пользователей с ролью MANAGER.

### Описание страницы

Страница перемещения товаров позволяет перенести товар из одной ячейки в другую.

![a](/docs/08-ui/images/move.png)

### Пошаговая инструкция

#### Шаг 1: Выбор товара

- В поле «Товар» выберите товар из выпадающего списка
- Отобразится таблица «Доступные остатки для выбранного товара» — здесь показано, в каких ячейках и в каком количестве есть этот товар

#### Шаг 2: Выбор исходной ячейки

- В поле «Из ячейки» выберите ячейку, из которой будет перемещён товар
- В выпадающем списке отображаются только ячейки, в которых есть выбранный товар

#### Шаг 3: Выбор целевой ячейки

- В поле «В ячейку» выберите ячейку, куда будет перемещён товар
- В выпадающем списке отображаются все доступные ячейки (кроме исходной)

#### Шаг 4: Указание количества

- В поле «Количество» укажите количество товара для перемещения
- Максимальное количество ограничено остатком в исходной ячейке

#### Шаг 5: Проверка информации

В блоке «Информация о перемещении» отображается сводка операции:

- Наименование товара
- Исходная ячейка
- Целевая ячейка
- Количество

#### Шаг 6: Подтверждение операции

- Проверьте правильность введённых данных
- Нажмите кнопку «Переместить товар»

### Результат

- При успешном выполнении операции вы будете перенаправлены на страницу сводки
- Остатки в исходной ячейке уменьшатся
- Остатки в целевой ячейке увеличатся (если товара там не было — создастся новая запись)

### Пример

**Входные данные:**

- Товар: Кирпич красный
- Исходная ячейка: А-1 (100 шт)
- Целевая ячейка: Б-2 (0 шт)
- Количество: 30 шт

**Результат:**

- В ячейке А-1: 70 шт
- В ячейке Б-2: 30 шт

## Управление пользователями

### Регистрация

Новые пользователи могут зарегистрироваться самостоятельно через форму регистрации.

### Роли пользователей

Система поддерживает две роли:

| Роль | Описание | Как получить |
|--------|--------|--------|
| USER | Обычный пользователь (только просмотр) | По умолчанию при регистрации |
| MANAGER | Менеджер склада (полный доступ) | Только через прямое изменение в базе данных или административный интерфейс |

### Изменение роли (для администратора)

Для назначения роли MANAGER необходимо выполнить SQL-запрос:

```sql
UPDATE users SET role = 'MANAGER' WHERE email = 'user@example.com';
```

## Роли и права доступа

### Матрица доступа

| Операция | USER | MANAGER |
|-----------|------|---------|
| Вход в систему | ✅ | ✅ |
| Регистрация | ✅ | ✅ |
| Просмотр сводки по складу | ✅ | ✅ |
| Просмотр остатков товара по ячейкам | ✅ | ✅ |
| Массовая приёмка товаров | ❌ | ✅ |
| Массовая отгрузка товаров | ❌ | ✅ |
| Перемещение товаров | ❌ | ✅ |

### Отображение интерфейса в зависимости от роли

- Пользователи с ролью USER видят в навигации только пункт «Остатки»
- Пользователи с ролью MANAGER видят все пункты навигации

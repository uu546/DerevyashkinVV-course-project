### 2. Расчёт по модели COCOMO

#### 2.1. Базовая модель COCOMO

COCOMO (COnstructive COst MOdel) — модель оценки трудоёмкости разработки программного обеспечения.

**Формула для органического типа проекта:**

```text
Effort = a * (KSLOC)^b * EAF
```

где:

* `a = 2.4` (коэффициент для органического проекта)
* `b = 1.05` (коэффициент масштаба)
* `KSLOC` — размер проекта в тысячах строк кода
* `EAF` — коэффициент корректировки (по умолчанию 1.0)

#### 2.2. Расчёт трудоёмкости

**Исходные данные:**

* Размер проекта: 5.9 KSLOC (~5900 строк)
* Тип проекта: органический (небольшой проект)

**Базовый расчёт:**

```text
Effort = 2.4 * (5.9)^1.05 = 2.4 * 6.45 ≈ 15.5 человеко-месяцев
```

#### 2.3. Коэффициент корректировки (EAF)

| Фактор                          | Оценка                        | Коэффициент |
| ------------------------------- | ----------------------------- | ----------- |
| Надёжность ПО                   | Низкая (малый бизнес)         | 0.88        |
| Размер БД                       | Средний                       | 1.00        |
| Сложность продукта              | Низкая                        | 0.85        |
| Требования к производительности | Средние                       | 1.00        |
| Ограничения памяти              | Отсутствуют                   | 1.00        |
| Волатильность окружения         | Низкая                        | 0.87        |
| Время восстановления            | Стандартное                   | 1.00        |
| Возможности аналитика           | Высокие                       | 0.94        |
| Возможности разработчика        | Высокие                       | 0.91        |
| Возможности виртуальной машины  | Современные                   | 1.00        |
| Требуемый график                | Ограничен (6 месяцев)         | 1.10        |
| Средства разработки             | Современные (Spring, Angular) | 0.90        |

**Итоговый EAF:**

```text
EAF = 0.88 * 1.00 * 0.85 * 1.00 * 1.00 * 0.87 * 1.00 * 0.94 * 0.91 * 1.00 * 1.10 * 0.90
EAF = 0.88 * 0.85 = 0.748
0.748 * 0.87 = 0.651
0.651 * 0.94 = 0.612
0.612 * 0.91 = 0.557
0.557 * 1.10 = 0.613
0.613 * 0.90 = 0.552
```

**EAF ≈ 0.55**

#### 2.4. Скорректированная трудоёмкость

```text
Effort_corrected = 15.5 * 0.55 ≈ 8.5 человеко-месяцев
```

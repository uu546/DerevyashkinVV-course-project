## Этап 12: Завершение

Завершить документацию проекта, подготовив все необходимые артефакты, включая руководство администратора, техническое задание, оценку трудозатрат, диаграмму Ганта и иерархическую структуру работ.

**В рамках этапа решаются следующие задачи:**

1. **Руководство администратора** — описание развёртывания, настройки и эксплуатации системы.

2. **Техническое задание** — требования к системе.

3. **Оценка трудозатрат (COCOMO)** — расчёт объёма кода и трудоёмкости проекта.

4. **Диаграмма Ганта** — визуализация сроков выполнения работ.

5. **Иерархическая структура работ (WBS)** — декомпозиция проекта на задачи и подзадачи.

**Результат этапа:** Полный комплект документации, готовый для защиты курсовой работы.

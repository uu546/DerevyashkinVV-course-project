### Контрольные точки

| Код | Наименование | Критерий качества |
|------|--------------|-------------------|
| 1.1 | Бизнес-анализ | Утверждённый паспорт проекта, BUC-диаграмма |
| 1.2 | Архитектура | Утверждённая архитектура PCMEF, ADR |
| 1.3 | База данных | DDL-скрипты, JPA-сущности |
| 1.4 | Детальное проектирование | Sequence диаграммы, спецификация методов |
| 1.5 | Реализация ядра | Рабочее приложение, CRUD-операции |
| 1.6 | Тестирование | Покрытие кода ≥40%, все тесты проходят |
| 1.7 | Рефакторинг | Код соответствует стандартам, ошибки исправлены |
| 1.8 | UI разработка | Полностью работающее Angular-приложение |
| 1.9 | API документация | Swagger UI, описание всех эндпоинтов |
| 1.10 | Документация | Полные руководства пользователя и администратора |
| 1.11 | Завершение | Все артефакты готовы|

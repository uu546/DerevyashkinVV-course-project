## Этап 9: Api 

### Цель этапа

Создать и задокументировать REST API для взаимодействия между фронтенд-приложением (Angular) и бэкенд-сервером (Spring Boot), а также обеспечить безопасность API с использованием JWT-аутентификации и разграничения прав доступа на основе ролей.

## Содержание

| № | Раздел  | Ссылка |
|---|---------|--------|
| 1 | Описание API (эндпоинты, запросы, ответы) |[Перейти](api-endpoints.md) |
| 2 | JWT-аутентификация и роли | [Перейти](security.md) |


**В рамках этапа решаются следующие задачи:**

1. **Определение структуры API** — проектирование эндпоинтов, HTTP-методов, форматов запросов и ответов.

2. **Реализация контроллеров** — создание REST контроллеров на Spring Boot для обработки запросов.

3. **Документирование API** — описание всех эндпоинтов с примерами запросов и ответов.

4. **Настройка безопасности** — реализация JWT-аутентификации, разграничение доступа на основе ролей USER/MANAGER.

5. **Интеграция с фронтендом** — обеспечение возможности взаимодействия Angular-приложения с API.

**Результат этапа:** Полностью функционирующее REST API с документацией, поддерживающее JWT-аутентификацию и ролевую модель доступа.

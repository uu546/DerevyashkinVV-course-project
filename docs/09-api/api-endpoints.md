
## REST API — Документация эндпоинтов
### Базовый URL

```java
http://localhost:8080/api
```
### Swagger UI
```
http://localhost:8080/swagger
```

### Форматы данных

| Аспект | Значение |
|--------|----------|
| **Content-Type** | `application/json` |
| **Accept** | `application/json` |
| **Кодировка** | UTF-8 |

### Коды ответов

| Код | Описание |
|-----|----------|
| `200 OK` | Запрос успешно выполнен |
| `201 Created` | Ресурс успешно создан |
| `400 Bad Request` | Неверный запрос (ошибка валидации) |
| `401 Unauthorized` | Отсутствует или недействительный токен |
| `403 Forbidden` | Недостаточно прав для выполнения операции |
| `404 Not Found` | Ресурс не найден |
| `500 Internal Server Error` | Внутренняя ошибка сервера |

## 1. Аутентификация (Authentication)

### 1.1. Регистрация пользователя

**Эндпоинт:** `POST /auth/register`

**Описание:** Регистрация нового пользователя в системе. Создаётся пользователь с ролью USER. Пароль хешируется с помощью BCrypt.

**Запрос:**
```json
{
  "email": "user@example.com",
  "password": "password123",
  "fullName": "Иван Иванов"
}
```

| Поле       | Тип      | Обязательное | Описание                              |
|------------|----------|--------------|---------------------------------------|
| email      | string   | Да           | Email пользователя (уникальный)      |
| password   | string   | Да           | Пароль (минимум 6 символов)           |
| fullName   | string   | Нет          | Полное имя пользователя               |

#### Успешный ответ (200 OK)

```json
{
  "accessToken": "eyJhbGciOiJIUzUxMiJ9...",
  "tokenType": "Bearer",
  "email": "user@example.com",
  "fullName": "Иван Иванов",
  "role": "USER",
  "expiresIn": 86400000
}
```

#### Возможные ошибки
| Код | Причина |
| --- | --- |
| **400** | Неверный формат email или короткий пароль |
| **409** | Пользователь с таким email уже существует |


## 1.2. Вход в систему

**Эндпоинт:** `POST /auth/login`

**Описание:** Аутентификация пользователя. При успешной проверке возвращается JWT-токен.

### Запрос

```json
{
  "email": "user@example.com",
  "password": "password123"
}
```

| Поле     | Тип    | Обязательное | Описание           |
| -------- | ------ | ------------ | ------------------ |
| email    | string | Да           | Email пользователя |
| password | string | Да           | Пароль             |

### Успешный ответ (200 OK)

```json
{
  "accessToken": "eyJhbGciOiJIUzUxMiJ9...",
  "tokenType": "Bearer",
  "email": "user@example.com",
  "fullName": "Иван Иванов",
  "role": "USER",
  "expiresIn": 86400000
}
```

### Ошибки

| Код | Причина                   |
| --- | ------------------------- |
| 401 | Неверный email или пароль |

## 2. Движения товаров (Movements)

### 2.1. Массовая приёмка товаров

**Эндпоинт:** `POST /movements/receipt/batch`

**Описание:** Оформление приёмки нескольких товаров на склад. Увеличивает остатки в указанной локации.

#### Запрос

```json
{
  "toLocationId": 1,
  "items": [
    {
      "productId": 1,
      "quantity": 100
    },
    {
      "productId": 2,
      "quantity": 50
    }
  ]
}
```

| Поле              | Тип     | Обязательное | Описание                    |
| ----------------- | ------- | ------------ | --------------------------- |
| toLocationId      | integer | Да           | ID целевой локации (ячейки) |
| items             | array   | Да           | Список товаров              |
| items[].productId | integer | Да           | ID товара                   |
| items[].quantity  | integer | Да           | Количество (> 0)            |

#### Успешный ответ (201 Created)

```text
Товары успешно добавлены на склад
```

#### Ошибки

| Код | Причина                                    |
| --- | ------------------------------------------ |
| 400 | Неверные данные запроса                    |
| 401 | Отсутствует или недействительный токен     |
| 403 | Недостаточно прав (требуется роль MANAGER) |
| 404 | Товар или локация не найдены               |

---

### 2.2. Массовая отгрузка товаров

**Эндпоинт:** `POST /movements/shipment/batch`

**Описание:** Оформление отгрузки нескольких товаров со склада. Уменьшает остатки в указанной локации.

#### Запрос

```json
{
  "fromLocationId": 1,
  "items": [
    {
      "productId": 1,
      "quantity": 10
    },
    {
      "productId": 2,
      "quantity": 5
    }
  ]
}
```

| Поле              | Тип     | Обязательное | Описание                     |
| ----------------- | ------- | ------------ | ---------------------------- |
| fromLocationId    | integer | Да           | ID исходной локации (ячейки) |
| items             | array   | Да           | Список товаров               |
| items[].productId | integer | Да           | ID товара                    |
| items[].quantity  | integer | Да           | Количество (> 0)             |

#### Успешный ответ (201 Created)

```text
Товары успешно отгружены со склада
```

#### Ошибки

| Код | Причина                                         |
| --- | ----------------------------------------------- |
| 400 | Неверные данные запроса или недостаточно товара |
| 401 | Отсутствует или недействительный токен          |
| 403 | Недостаточно прав (требуется роль MANAGER)      |
| 404 | Товар или локация не найдены                    |

---

### 2.3. Перемещение товара

**Эндпоинт:** `POST /movements/move`

**Описание:** Перемещение товара из одной локации в другую.

#### Запрос

```json
{
  "productId": 1,
  "fromLocationId": 1,
  "toLocationId": 2,
  "quantity": 30
}
```

| Поле           | Тип     | Обязательное | Описание            |
| -------------- | ------- | ------------ | ------------------- |
| productId      | integer | Да           | ID товара           |
| fromLocationId | integer | Да           | ID исходной локации |
| toLocationId   | integer | Да           | ID целевой локации  |
| quantity       | integer | Да           | Количество (> 0)    |

#### Успешный ответ (200 OK)

```json
{
  "movementId": 123,
  "status": "OK",
  "message": "Товар успешно перемещён",
  "movementDate": "2024-01-15"
}
```

#### Ошибки

| Код | Причина                                    |
| --- | ------------------------------------------ |
| 400 | Недостаточно товара в исходной локации     |
| 401 | Отсутствует или недействительный токен     |
| 403 | Недостаточно прав (требуется роль MANAGER) |
| 404 | Товар или локация не найдены               |

## 3. Информация об остатках (Inventory)

### 3.1. Получение сводки по складу

**Эндпоинт:** `GET /inventory/summary`

**Описание:** Возвращает полную информацию о всех складах, локациях и остатках товаров.

#### Успешный ответ (200 OK)

```json
{
  "warehouses": [
    {
      "warehouseId": 1,
      "warehouseName": "Основной склад",
      "warehouseAddress": "г. Москва, ул. Ленина, 1",
      "locations": [
        {
          "locationId": 1,
          "locationName": "А-1",
          "locationType": "Стеллаж",
          "products": [
            {
              "productId": 1,
              "productName": "Кирпич красный",
              "unit": "шт",
              "quantity": 500,
              "isPerishable": false
            }
          ],
          "totalItems": 500
        }
      ],
      "totalItems": 500
    }
  ],
  "totalSummary": {
    "totalWarehouses": 1,
    "totalLocations": 1,
    "totalProducts": 1,
    "totalItems": 500
  }
}
```

#### Ошибки

| Код | Причина                                |
| --- | -------------------------------------- |
| 401 | Отсутствует или недействительный токен |

---

### 3.2. Остатки товара по локациям

**Эндпоинт:** `GET /inventory/product/{productId}/locations`

**Описание:** Возвращает список всех локаций, где есть указанный товар, с указанием количества.

#### Параметры пути

| Параметр  | Тип     | Описание  |
| --------- | ------- | --------- |
| productId | integer | ID товара |

#### Успешный ответ (200 OK)

```json
[
  {
    "locationId": 1,
    "locationName": "А-1",
    "locationFullName": "Основной склад - А-1",
    "locationType": "Стеллаж",
    "warehouseName": "Основной склад",
    "quantity": 500,
    "unit": "шт"
  },
  {
    "locationId": 2,
    "locationName": "Б-2",
    "locationFullName": "Основной склад - Б-2",
    "locationType": "Паллета",
    "warehouseName": "Основной склад",
    "quantity": 200,
    "unit": "шт"
  }
]
```

#### Справочники

| Метод | Эндпоинт                  | Описание                        | Доступ         |
|-------|---------------------------|---------------------------------|----------------|
| GET   | `/api/products`           | Получение списка товаров        | USER, MANAGER  |
| GET   | `/api/products/{id}`      | Получение товара по ID          | USER, MANAGER  |
| GET   | `/api/locations`          | Получение списка локаций        | USER, MANAGER  |
| GET   | `/api/locations/{id}`     | Получение локации по ID         | USER, MANAGER  |

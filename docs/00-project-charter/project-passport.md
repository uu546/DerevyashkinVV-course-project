## 2. БИЗНЕС-КОНТЕКСТ

**Проблема:** Малые и средние предприятия сталкиваются с трудностями при ведении складского учёта с использованием электронных таблиц и бумажных журналов. Это приводит к ошибкам в остатках товаров, потерям времени на поиск товаров и сверку данных, задержкам в операциях приёмки и отгрузки.

**Решение:** Разработка веб-приложения «Система управления складом», которая автоматизирует ключевые процессы:

- учёт товаров с привязкой к категориям и единицам измерения;
- оформление приёмки и отгрузки товаров;
- перемещение товаров между складскими ячейками;
- просмотр актуальных остатков по складам, ячейкам и товарам.

Система предоставляет сотрудникам централизованное рабочее место с актуальными данными и разграничение прав доступа на основе ролей (USER — только просмотр, MANAGER — полный доступ).

---

## 3. ЦЕЛИ ПРОЕКТА

1. **Повышение точности учёта:** Снизить уровень расхождений между фактическими и учётными остатками.

2. **Ускорение складских операций:** Сократить среднее время оформления операции приёмки/отгрузки с 30 до 10 минут (на 66%).

3. **Обеспечение прозрачности:** Предоставить руководству инструмент для онлайн-мониторинга складских остатков и движений товаров.

4. **Удобство массовых операций:** Реализовать возможность добавления нескольких товаров в приходе/расходе за один запрос.

5. **Разграничение доступа:** Реализовать ролевую модель (USER/MANAGER) для обеспечения безопасности и контроля действий пользователей.

## Этап 2: Архитектура

### Цель этапа

Спроектировать архитектуру программной системы «Управление складом» на основе архитектурного паттерна PCMEF, обеспечивающую:

- чёткое разделение ответственности между слоями;
- слабую связанность компонентов;
- высокую тестируемость;
- возможность независимого изменения и масштабирования отдельных слоёв.

**В рамках этапа решаются следующие задачи:**

1. **Выбор и обоснование архитектурного стиля** - анализ альтернатив, выбор PCMEF, адаптация под веб-траекторию (Web).

2. **Определение слоёв PCMEF** - описание назначения каждого слоя (Presentation, Control, Mediator, Entity, Foundation) и его роли в системе.

3. **Построение диаграммы пакетов** - визуализация структуры проекта с выделением слоёв и их зависимостей.

4. **Формализация правил зависимостей**-— обеспечение направленности зависимостей «сверху вниз» (P  C  M  E  F).

5. **Спецификация интерфейсов между слоями** - описание контрактов взаимодействия между Mediator и Foundation для реализации принципа инверсии зависимостей (DIP).

6. **Фиксация архитектурных решений (ADR)** - документирование ключевых архитектурных выборов, их обоснование и альтернативы.

**Результат этапа:** Архитектурный каркас системы, представленный в виде диаграмм, текстового описания и документированных архитектурных решений, который служит основой для детального проектирования, реализации и тестирования на последующих этапах.

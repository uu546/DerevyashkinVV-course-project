## Этап 8: Интерфейс 

### Цель этапа

Разработать и задокументировать пользовательский интерфейс системы управления складом, обеспечивающий удобное и интуитивно понятное взаимодействие пользователя с функциональностью системы.

**В рамках этапа решаются следующие задачи:**

1. **Реализация клиентской части приложения** — разработка веб-интерфейса на Angular с использованием компонентного подхода.

2. **Интеграция с бэкендом** — подключение к REST API, обработка асинхронных запросов, отображение данных.

3. **Реализация маршрутизации** — настройка навигации между страницами с использованием Angular Router.

4. **Управление состоянием** — использование сервисов и сигналов для управления данными приложения.

5. **Валидация форм** — проверка вводимых пользователем данных на стороне клиента.

**Результат этапа:** Полностью функционирующее веб-приложение с интуитивно понятным интерфейсом, позволяющее пользователям выполнять все основные операции системы управления складом.

### Основные страницы приложения

| Страница | Маршрут | Описание |
|----------|---------|----------|
| **Авторизация** | `/login` | Вход в систему по email и паролю |
| **Регистрация** | `/register` | Создание новой учётной записи |
| **Сводка по складу** | `/inventory/summary` | Просмотр остатков по складам, ячейкам и товарам |
| **Приёмка товаров** | `/movements/receipt` | Массовое добавление товаров на склад |
| **Отгрузка товаров** | `/movements/shipment` | Массовое списание товаров со склада |
| **Перемещение товаров** | `/movements/transfer` | Перемещение товаров между ячейками |

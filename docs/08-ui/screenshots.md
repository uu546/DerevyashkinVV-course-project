## Скриншоты пользовательского интерфейса

### Страница авторизации пользователя
![alt text](/docs/08-ui/images/auth.png)
*Страница авторизации позволяет пользователю войти в систему, указав email и пароль. При успешной аутентификации пользователь получает JWT-токен и перенаправляется на страницу сводки по складу.*

### Страница регистрации нового пользователя
![alt text](/docs/08-ui/images/register.png)
*Страница регистрации нового пользователя. Запрашивается ФИО, email и пароль (с подтверждением). После успешной регистрации пользователь автоматически входит в систему.*


### Информация по остаткам на складе
![alt text](/docs/08-ui/images/summary.png)
*Главная страница приложения показывает сводную информацию по складам:*
- *Общая статистика (количество складов, ячеек, позиций, единиц товаров)*
- *Детальная информация по каждому складу*
- *Список ячеек с указанием типа и количества товаров*
- *Список товаров в каждой ячейке с единицами измерения*

### Приёмка товаров на склад
![alt text](/docs/08-ui/images/receipt.png)
*Страница приёмки товаров позволяет:*
- *Выбрать целевую ячейку для размещения товаров*
- *Добавить несколько товаров за один запрос*
- *Выбрать товар из выпадающего списка (ID, название, единица измерения)*
- *Указать количество для каждого товара*
- *Удалить позицию при необходимости*
  
*Кнопка «Оформить приёмку» отправляет запрос на сервер и при успехе перенаправляет на страницу сводки.*

### Отгрузка товаров со склада
![alt text](/docs/08-ui/images/shipment.png)
*Страница отгрузки товаров позволяет:*
- *Выбрать исходную ячейку для отгрузки*
- *Добавить несколько товаров за один запрос*
- *Выбрать товар из выпадающего списка*
- *Указать количество (ограниченное доступным остатком)*
- *Удалить позицию при необходимости*

*Перед отгрузкой система проверяет достаточность остатков. Кнопка «Оформить отгрузку» отправляет запрос на сервер и при успехе перенаправляет на страницу сводки.*


### Перемещение товаров между ячейками
![alt text](/docs/08-ui/images/move.png)
*Страница перемещения товаров позволяет:*
- *Выбрать товар из выпадающего списка*
- *Просмотреть таблицу доступных остатков по всем ячейкам*
- *Выбрать исходную ячейку (откуда перемещаем)*
- *Выбрать целевую ячейку (куда перемещаем)*
- *Указать количество (ограниченное остатком в исходной ячейке)*

*При выборе товара автоматически загружаются все ячейки с его остатками. Целевая ячейка может быть любой (не только с наличием товара).*

### Основные возможности интерфейса

#### 1. Аутентификация и авторизация
* Регистрация нового пользователя с ролью `USER`
* Вход в систему с получением JWT-токена
* Разграничение доступа: `USER` — только просмотр, `MANAGER` — полный доступ
* Автоматическое добавление токена во все запросы (*HTTP interceptor*)

#### 2. Сводка по складу
* Отображение общей статистики (количество складов, ячеек, позиций, единиц)
* Группировка по складам
* Детализация по ячейкам с указанием типа и количества
* Отображение товаров в каждой ячейке с единицами измерения

#### 3. Приёмка товаров
* Выбор целевой ячейки из выпадающего списка
* Добавление нескольких товаров за один запрос (массовая операция)
* Выбор товара из справочника с указанием единицы измерения
* Валидация количества (должно быть больше 0)

#### 4. Отгрузка товаров
* Выбор исходной ячейки из выпадающего списка
* Просмотр доступных остатков перед отгрузкой
* Добавление нескольких товаров за один запрос
* Валидация количества (не может превышать доступный остаток)

#### 5. Перемещение товаров
* Выбор товара из справочника
* Отображение всех ячеек с остатками выбранного товара
* Выбор исходной и целевой ячейки
* Валидация количества и доступности

#### 6. Ролевая модель

| Роль | Доступные операции |
| :--- | :--- |
| **USER** | Просмотр сводки по складу |
| **MANAGER** | Просмотр сводки, приёмка, отгрузка, перемещение |


### 7. Навигационная панель (Header)

![Навигационная панель](/docs/08-ui/images/header.png)
*Навигационная панель отображается для авторизованных пользователей и содержит:*
- *название системы (ссылка на сводку)*
- *Ссылки на основные разделы: Остатки, Приёмка, Отгрузка, Перемещение*
- *Информацию о текущем пользователе (ФИО и роль)*
- *Кнопку «Выйти» для завершения сессии*

*Для пользователей с ролью USER ссылки на операции (Приёмка, Отгрузка, Перемещение) скрыты.*

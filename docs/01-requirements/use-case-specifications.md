# 3. Спецификация прецедентов
## Use Case UC-02: Оформление приёмки товара

| Параметр | Значение |
|-----------|-----------|
| **ID** | UC-02 |
| **Название** | Оформление приёмки товара  |
| **Акторы** | Менеджер скалда  |
| **Описание** | Менеджер склада фиксирует в системе поступление товара. |
| **Предусловия** | 1. Поставщик прибыл с товаром и сопроводительными документами.<br>2. Товары присутствуют в справочнике номенклатуры. |
| **Постусловия** | 1. Создана запись поставки.<br>2. Остатки товаров увеличены на указанное количество. |
| **Основной поток** | 1. Менеджер склада выбирает команду «Создать поставку.<br>2. Система предлагает выбрать ячейку и товар.<br>3. Менеджер склада сканирует или вводит товары вручную.<br>4. Система добавляет товары в поставку.<br>5. Система сохраняет поставку и обновляет остатки товаров. |
| **Подпотоки** | * Использование сканера штрих-кодов для ускоренного ввода товаров.<br>* Массовая приёмка нескольких товаров одной операцией. |
| **Потоки исключений** | * Товар отсутствует в справочнике.

## Use Case UC-03: Оформление отгрузки товара

| Параметр | Значение |
|-----------|-----------|
| **ID** | UC-03 |
| **Название** | Оформление отгрузки товара |
| **Акторы** | Менеджер склада |
| **Описание** | Менеджер склада фиксирует отгрузку товаров со склада |
| **Предусловия** | 1. Получена заявка на отгрузку.<br>2. Необходимые товары имеются на складе в достаточном количестве. |
| **Постусловия** | 1. Создана отгрузка.<br>2. Остатки товаров уменьшены на указанное количество. |
| **Основной поток** | 1. Менеджер склада выбирает команду «Создать отгрузку.<br>2. Система отображает доступные товары и места их хранения.<br>3. Менеджер склада выбирает товары и указывает количество.<br>4. Система проверяет достаточность остатков.<br>5. Менеджер склада подтверждает операцию.<br>6. Система сохраняет отгрузку и обновляет остатки товаров. |
| **Подпотоки** | * Массовая отгрузка нескольких товаров в рамках одной операции отгрузки. |
| **Потоки исключений** | * Недостаточно товара на складе - система уведомляет пользователя и предлагает скорректировать количество. |


## Use Case UC-04: Перемещение товара между локациями

| Параметр | Значение |
|-----------|-----------|
| **ID** | UC-04 |
| **Название** | Перемещение товара между локациями |
| **Акторы** | Менеджер склада |
| **Описание** | Менеджер склада выполняет перемещение товара из одной ячейки хранения в другую. |
| **Предусловия** | 1. Товар присутствует в исходной ячейке в достаточном количестве.<br>2. Целевая ячейка существует и доступна для размещения товара. |
| **Постусловия** | 1. Остатки в исходной ячейке уменьшены.<br>2. Остатки в целевой ячейке увеличены либо создана новая запись об остатке. |
| **Основной поток** | 1. Менеджер склада выбирает команду «Переместить товар».<br>2. Выбирает товар, исходную и целевую ячейки хранения.<br>3. Указывает количество для перемещения.<br>4. Система проверяет достаточность остатка в исходной ячейке.<br>5. Менеджер склада подтверждает операцию.<br>6. Система обновляет остатки и регистрирует перемещение товара. |
| **Подпотоки** | * При отсутствии остатка в целевой ячейке система автоматически создаёт новую запись в учёте остатков. |
| **Потоки исключений** | * Недостаточно товара в исходной ячейке - система выводит сообщение об ошибке.

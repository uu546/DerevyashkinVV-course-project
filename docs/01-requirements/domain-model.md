## Описание сущностей

Представлены основные сущности предметной области системы складского учёта, их ключевые атрибуты и назначение.

| Сущность | Атрибуты | Описание |
|-----------|-----------|-----------|
| **User** | id, email, password, fullName, role, isActive | Пользователь системы. Роль определяет набор доступных операций и уровень доступа к данным. |
| **Product** | id, name, description, isPerishable, expiryDays | Товар, учитываемый в системе. Содержит информацию о скоропортящемся характере товара и сроке его хранения. |
| **Category** | id, title | Категория товара, используемая для классификации и группировки номенклатуры. |
| **Unit** | id, title | Единица измерения товара (например, штуки, килограммы, литры). |
| **Warehouse** | id, name, address | Склад — физическое место хранения товаров. |
| **Location** | id, name, fullName | Ячейка хранения внутри склада (стеллаж, паллета, холодильная камера и т.д.). |
| **Type** | id, title | Тип ячейки хранения (стеллаж, паллета, холодильник и др.). |
| **Temperature** | id, title | Температурный режим хранения товаров. |
| **Inventory** | id, quantity | Остаток конкретного товара в определённой ячейке хранения. |
| **Movement** | id, quantity, movementDate | Операция движения товара: приёмка, отгрузка или внутреннее перемещение. |


## Бизнес-правила

Бизнес-правила определяют ограничения и требования, обеспечивающие корректность работы системы складского учёта.

| № | Правило | Описание |
|----|----------|----------|
| **BR1** | Уникальность email | В системе не допускается наличие двух пользователей с одинаковым адресом электронной почты. |
| **BR2** | Уникальность (name, unit) | Не допускается создание двух товаров с одинаковым названием и одинаковой единицей измерения. |
| **BR3** | Положительное количество | Количество товара в операции движения должно быть больше нуля. |
| **BR4** | Неотрицательный остаток | Остаток товара в ячейке хранения не может принимать отрицательное значение. |
| **BR5** | Уникальность остатка | Для каждой пары «Товар – Ячейка хранения» может существовать только одна запись об остатке. |
| **BR6** | Доступ по роли | Пользователь с ролью **USER** имеет доступ только к просмотру данных, пользователь с ролью **MANAGER** имеет полный доступ к операциям системы. |
| **BR7** | Валидация количества при отгрузке | Количество отгружаемого товара не может превышать доступный остаток на складе. |
| **BR8** | Атомарность операции | Все изменения данных в рамках одной бизнес-операции должны выполняться в единой транзакции. |

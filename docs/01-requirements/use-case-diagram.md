# 1. Use Case диаграмма

Диаграмма вариантов использования (Use Case Diagram) показывает функциональные требования к системе с точки зрения акторов.

![alt text](/docs/01-requirements/images/use-case2.png)
## Акторы

Акторы представляют пользователей и внешние сущности, взаимодействующие с системой складского учёта.

| Актор | Описание |
|--------|--------|
| **Менеджер склада** | Выполняет складские операции |
| **Директор** | Мониторинг ключевых показателей эффективности (KPI) |
| **Бухгалтер** |Получение корректных первичных документов и данных для бухгалтерского учёта |

## Этап 10: Развёртывание

### Цель этапа

Описать процесс развёртывания.

---

## Способ развёртывания

Приложение разработано с использованием **Spring Boot** и собирается в исполняемый **JAR-файл**, который содержит встроенный сервер **Apache Tomcat**. Это позволяет запускать приложение без установки и настройки внешнего веб-сервера.

| Параметр | Значение |
|----------|----------|
| **Тип сборки** | JAR (исполняемый) |
| **Встроенный сервер** | Apache Tomcat (встроенный в Spring Boot) |
| **Порт по умолчанию** | 8080 |
| **Запуск** | `java -jar warehouse-management-api-1.0.0.jar` |

### Преимущества подхода

| Преимущество | Описание |
|--------------|----------|
| **Простота развёртывания** | Не требуется установка и настройка отдельного сервера приложений |
| **Автономность** | Всё необходимое для работы (включая сервер) находится внутри JAR |
| **Единообразие** | Одинаковый способ запуска в средах разработки, тестирования и эксплуатации |


## Заключение

Развёртывание системы управления складом выполняется в виде исполняемого JAR-файла со встроенным сервером Tomcat.

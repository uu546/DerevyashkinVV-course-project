# Система управления складом (Warehouse Management System)

**Система управления складом** — это веб-приложение для автоматизации складского учёта на малых и средних предприятиях. Система позволяет отслеживать остатки товаров, оформлять приёмку и отгрузку товаров (в том числе массовыми партиями), перемещать товары между складскими ячейками, а также просматривать сводную информацию по складам в реальном времени.

## Возможности системы

- ✅ **Приёмка товаров** —  добавление нескольких товаров на склад 
- ✅ **Отгрузка товаров** —  списание товаров со склада с проверкой достаточности остатков
- ✅ **Перемещение товаров** — перенос товаров между ячейками хранения
- ✅ **Просмотр остатков** — сводка по складам, ячейкам и товарам в реальном времени
- ✅ **Аутентификация и авторизация** — JWT-токены, регистрация, вход, разграничение ролей
- ✅ **Ролевая модель** — USER (только просмотр) и MANAGER (полный доступ)

## Запуск проекта

### Требования

| Компонент | Версия |
|-----------|--------|
| Java | 17+ |
| PostgreSQL | 15+ |
| Node.js | 18+ |
| Angular CLI | 17+ |

### Запуск бэкенда

```bash
cd warehouse-management-api
mvn spring-boot:run
```

Бэкенд будет доступен по адресу: http://localhost:8080

## Запуск фронтенда

```bash
cd warehouse-frontend
npm install
ng serve
```

Фронтенд будет доступен по адресу: http://localhost:4200
